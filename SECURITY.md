# Security policy

This is research software and has not received a production security audit.
Raw sensor samples remain on the phone in the intended training flow, but split
activations, gradients, checkpoints, logs, and generated assessments may still
contain sensitive information. The current research transport must not be
assumed to provide production-grade confidentiality or authentication.

Do not submit real credentials, personal sensor records, model licenses,
private device identifiers, or security-sensitive traces in public issues.
Report a suspected vulnerability privately to the repository maintainers using
GitHub's private vulnerability reporting feature once it is enabled.
