# Contributing

This public source snapshot does not currently grant a reuse license and is not
accepting unsolicited code contributions. Contact the maintainers before
opening a pull request. Contribution and licensing terms will be documented
before external contributions are accepted.

Do not submit code copied from unlicensed projects, model or dataset assets,
generated `.pte` programs, checkpoints, SDK binaries, credentials, personal
sensor data, or device identifiers.
